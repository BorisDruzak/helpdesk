# Открытие тикета из строки очереди

Actor: support. Основная задача — открыть карточку обращения из списка. Страница сохраняет структуру List+Detail, фильтры и рабочую карточку; редкие операции остаются в существующих инструментах.

Верхний переключатель «Свёрнута / Рядом с тикетом / Вся очередь» удалён. Режимы доступны через две кнопки очереди: меню переключает список и миниатюры, стрелка открывает полный список. Из полного списка можно вернуться к текущему обращению. На телефоне соответствующие иконки доступны в панели действий карточки; интерфейс не зависит от удалённого переключателя.

В полной таблице восемь столбцов, без столбца «Действие». Нажатие на любую обычную ячейку открывает подробную карточку тикета. Это просмотр: он не назначает исполнителя, не меняет статус и не начинает работу. «Взять в работу» остаётся действием самой карточки с существующими серверными проверками. Строка доступна с клавиатуры: Enter/Space; кнопка номера также открывает карточку. Выделение текста и вложенные элементы управления не вызывают повторный переход.

Смена вида очереди сохраняет текст и вложения текущего обращения. Автоматическое сворачивание выполняется только после успешного начала работы. Права, SLA, OLA, маршрутизация, расчёт сроков, очередь действий и существующие услуги не изменяются.

## OLA в схеме

Отдельного OLA-блока в `ScenarioBlock` сейчас нет. Контракт поддерживает правило `process_binding.policy_refs.ola`; публикация переносит его в политику услуги/шаблона. Движок OLA устанавливает внутренние сроки подтверждения и обработки с учётом политики, очереди и приоритета, если функция включена и целевые сроки заданы. Наличие SLA-блока не означает, что OLA автоматически настроена. Проверка этой задачи не меняет OLA-политики или схему старых услуг.

1. RED→GREEN для отсутствия переключателя/столбца, клика по ячейке, клавиатуры и отсутствия начала работы.
2. Проверить сохранение ответа/вложений, мобильные иконки, ошибки/пустой список и размеры1366/1440/1920/390; независимый обзор.
3. Штатный guarded release на staging, сверка исходных услуг/черновиков, health/ресурсов и новой браузерной вкладки. Production не изменяется.
