# Тестирование динамических модулей

## Описание

Этот пример демонстрирует новые возможности оркестратора:
- **Динамическую установку модулей** через команду `install_module`
- **Выполнение скриптов в памяти** через команду `exec_script`
- **Автоматический проброс модулей** в контекст выполнения скриптов
- **Валидацию кода** через `CodeValidator`

## Запуск тестов

### Основной тест динамических модулей
```bash
cd /var/chat_bot/pc_client/pc_agent
python examples/test_dynamic_modules.py
```

### Примеры использования exec_script с автопробросом модулей
```bash
cd /var/chat_bot/pc_client/pc_agent
python examples/exec_script_example.py
```

## Что тестируется

1. **Установка class-based модуля** - модуль с классом, наследующим `BaseCollector`
2. **Установка function-based модуля** - модуль с асинхронной функцией `run`
3. **Список загруженных модулей** - проверка, что модули успешно загружены
4. **Сбор данных** - получение данных с динамически установленных модулей
5. **Выполнение одноразового скрипта** - запуск кода без сохранения на диск
6. **Валидация невалидного кода** - проверка обработки ошибок

## Ожидаемый результат

Все тесты должны пройти успешно:
- ✅ Class-based модуль установлен и работает
- ✅ Function-based модуль установлен и работает
- ✅ Список модулей показывает оба модуля
- ✅ Команда `collect` возвращает данные от обоих модулей
- ✅ Одноразовый скрипт выполняется успешно
- ✅ Невалидный код корректно отклоняется с ошибкой

## Расположение установленных модулей

Динамически установленные модули сохраняются в:

```
pc_agent/modules/dynamic/
├── custom_collector.py
└── quick_check.py
```

## Очистка

Чтобы очистить установленные модули:

```bash
rm -rf /var/chat_bot/pc_client/pc_agent/modules/dynamic/*.py
```

## Интеграция с WebSocket агентом

Те же команды можно отправлять через WebSocket:

### Установка модуля
```json
{
  "command": "install_module",
  "params": {
    "name": "my_module",
    "code": "..."
  }
}
```

### Выполнение скрипта с автопробросом модулей
```json
{
  "command": "exec_script",
  "params": {
    "code": "async def run():\n    # Все загруженные модули доступны автоматически!\n    data = await system.collect()\n    logger.info(f'CPU: {data[\"cpu\"]}%')\n    return {'cpu': data['cpu']}"
  }
}
```

**Важно:** Все модули, загруженные через `install_module` или указанные в `enabled_modules`, автоматически доступны в скриптах по их имени (`module.name`).

## Безопасность

⚠️ **Внимание**: Команды `install_module` и `exec_script` выполняют произвольный Python код. 

В production среде необходимо:
- Реализовать аутентификацию
- Добавить белый список разрешенных операций
- Использовать sandbox для изоляции кода
- Логировать все операции установки и выполнения
