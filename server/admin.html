Зачем нужен этот раздел

Здесь настраивается, как HelpDesk принимает и обрабатывает заявки: очереди, маршрутизация, SLA, приоритеты, OLA и аудит.

Изменения влияют на то, куда попадёт тикет, кто его увидит, когда сработает эскалация и как считаются сроки.

Обновление агентов

                    
Серверный rollout — источник истины для версий агента. В настройках держите приоритетную версию и набор build-ов на сервере, а расширенные действия используйте для canary, диагностики и массовой раскатки.

Массовое обновление

                    
Target подбирается по ОС устройства. Bulk режим живёт по контракту canary-first: при включённом флаге сервер не пустит массовую раскатку без подтверждённой canary-операции.

Глобальный rollout

                    
Назначенный build становится server-side rollout policy и используется как приоритетная версия для self-update, ручного запуска без явной версии и массовой раскатки по target.

                    

                        

                            
                            
                            
                        

                        

                            
                            
                        

                    

                    

                        
Назначенные rollout версии ещё не загружены.

                    

                


                

                    
Загрузка билда

                    
Загрузите архив агента для нужного target. Для Windows и Linux версии ведутся независимо, а priority rollout назначается отдельно по каждому target.

                    

                        

                            
                            
                        

                        

                            
                            
                        

                        

                            
                            
                        

                        

                            
                            
                        

                        

                            
                            
                        

                        

                            
                            
                        

                        

                            
                        

                    

                    

                    

                


                

                    
Доступные билды

                    
Удаляйте старые версии только после снятия rollout policy. Assigned build защищён серверным контрактом и не может быть удалён, пока он источник истины для target.
